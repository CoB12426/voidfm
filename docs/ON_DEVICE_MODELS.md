# Preparing Models for On-Device Mode

Choose **On-Device** under Settings → DJ ENGINE to generate DJ talk on the phone alone, without a PC. Scripts are generated by Gemma 4 E2B IT on LiteRT-LM, and speech by Supertonic 3 on sherpa-onnx (English only).

## 1. Gemma 4 E2B (script generation)

1. Save `gemma-4-E2B-it.litertlm` from [litert-community/gemma-4-E2B-it-litert-lm](https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm/tree/main) to your device (about 2.6 GB).
2. Select it via Settings → **Select Gemma 4 E2B model**. The file is copied into app-private storage, so you need enough free space for the copy as well.

Legacy MediaPipe `.bin` files, GGUF, PyTorch weights, and arbitrary `.tflite` files are not supported. The app tries to start on the GPU and falls back to the CPU on devices where the GPU is unavailable.

## 2. Supertonic 3 (speech synthesis)

1. Save the [sherpa-onnx Supertonic 3 INT8 model](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/sherpa-onnx-supertonic-3-tts-int8-2026-05-11.tar.bz2) (`.tar.bz2`) to your device.
2. Select it via Settings → **Select Supertonic 3 archive**. The seven required files are extracted into the app. Selecting individual `.onnx` files will not work.

You can choose and preview 10 voices (F1–F5, M1–M5) and adjust the speaking rate with Speech Pace (default 0.85×). Supertonic 3 does not support inline performance tags, so tags such as `[laugh]` in the script are stripped before synthesis. The model is licensed under [OpenRAIL-M](https://huggingface.co/Supertone/supertonic-3).

## Notes

- ON AIR becomes available once both models are in place. Models are loaded when you go ON AIR, so the first intro takes a moment to play.
- All generation happens on the device. The network is used only to fetch fonts on first launch.
- Inference speed and memory usage vary widely between devices.
